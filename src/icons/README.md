# Картинки интерфейса

Что можно заменить, не трогая код:

| Файл | Где видно | Формат |
|---|---|---|
| `public/logo.png` | Список расширений в Owlbear Rodeo, иконка расширения в магазине | PNG, квадрат, 512×512 (сейчас 300×300 — рендер d10 из превью) |
| `public/icon.svg` | Кнопка расширения в панели действий Owlbear | SVG 24×24, одноцветный белый (`fill="#fff"`), фон прозрачный |
| `src/icons/difficulty.svg` | Значок сложности над лотком | SVG 24×24, одноцветный, любой цвет заливки: рисуется как маска цветом текста |
| `src/materials/custom/icons/*.svg` | Значки на гранях своих кубов | см. README в той папке |
| `src/materials/custom/fonts/*` | Шрифт цифр своих кубов | см. README в той папке |

Для значков интерфейса (`src/icons/*.svg`) важна только форма: файл накладывается как маска и красится в цвет текста (`FileIcon.tsx`). Тонкие линии тоньше 1,5 единиц из 24 при размере 16 px пропадут.

Остальные значки интерфейса (кубик в листе, переброс, глаз, замок, история) взяты из Material Icons через `@mui/icons-material`; чтобы заменить такой, положи SVG сюда и подключи его через `FileIcon` вместо импорта из `@mui/icons-material`.

Текстуры готовых кубов и лотка лежат в `src/materials/<стиль>/`: `albedo.jpg` (цвет), `normal.jpg` (нормали), `orm.jpg` (R — затенение, G — шероховатость, B — металличность), все 2048×2048 на общей развёртке; цифры в них запечены. Своим кубам эти файлы не нужны.
