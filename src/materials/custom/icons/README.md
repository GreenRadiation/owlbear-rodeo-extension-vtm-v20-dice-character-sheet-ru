# Значки для кастомных кубов

Каждый SVG-файл в этой папке — значок, который игрок может поставить на куб вместо «0» или «1». Новый файл появляется в настройках сам после сборки, код править не нужно. Имя файла (латиницей, без пробелов) — идентификатор значка: он хранится в настройках игроков и едет вместе с броском, поэтому готовые файлы лучше не переименовывать.

Как нарисовать значок:

- Квадрат 100×100: в корневом теге обязательно `width="100" height="100" viewBox="0 0 100 100"`.
- Важна только непрозрачность: всё, что закрашено, становится значком, прозрачное — корпусом куба. Цвет заливки значения не имеет, цвет значка игрок выбирает в настройках.
- Значок рисуется «головой вверх», поворот на грани расширение делает само.
- На кубе значок занимает около 96 пикселей текстуры, то есть примерно треть грани. Тонкие линии (тоньше 4 единиц из 100) пропадут, мелкие детали сольются.
- Дырки (глазницы черепа, петля анкха) делаются через `fill-rule="evenodd"` или `<mask>`, а не белой заливкой.
- Гравировка, шероховатость и свечение значка строятся из этой же картинки, отдельно их рисовать не нужно.

Значение броска от значка не зависит: оно читается по геометрии куба.
